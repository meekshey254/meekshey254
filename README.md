## 🧑‍💻 About Me

<img align="right" src="https://avatars.githubusercontent.com/u/147913414?v=4" width="155" alt="Meshack Muema Avatar" />

I'm **Meshack Muema** (**Meek**), a software developer passionate about turning real-world operational challenges into clean, reliable mobile and web applications.

- 🔭 **Currently Building:** A full-scale, **6-role School Management & Live Van Tracking App** built with **Flutter**, **Supabase (PostgreSQL + PostGIS + Realtime)**, and an **offline-first SQLite sync engine**.
- 🌱 **Currently Exploring:** Cross-platform **Flutter/Dart** architecture, geospatial geofencing with **PostGIS**, real-time cloud synchronization, and **Natural Language Processing (NLP)** with Python.

- 🤝 **Open For:** Open-source collaboration, software engineering roles, and impactful community projects.

<details>
<summary><b>🔍 Deep Dive: School Management & Live Van Tracking Architecture (Click to Expand)</b></summary>
<br/>

A unified **Flutter Android & Desktop application** backed by **Supabase (PostgreSQL + PostGIS + Realtime)** and an **on-device SQLite offline cache**:

| Role Portal | Key Capabilities |
| :--- | :--- |
| **👨‍👩‍👧 Parent Portal** | Multi-child switcher (`Combined Family Balance` vs. `Selected Child` itemized Tuition, Transport, Activity & Remedial fees), live **School Van 01** map & geofence alerts, 1-tap absence reporting, Guardian Pickup PIN, and printable PDF Report Cards. |
| **🚐 Van Driver Console** | Shared route stop progression, live GPS telemetry, `500m Approaching` / `80m Arrived` / `150m School` PostGIS triggers, 1-tap `Boarded`/`Dropped Off` actions, and mandatory **"No Child Left Behind"** post-trip cabin verification. |
| **👩‍🏫 Class Teacher Dashboard** | Daily classroom roll-call, exam mark entry with **Subject Teacher Remarks**, 1-click **Auto-Ranking Leaderboard**, and contextualized 1-to-1 parent messaging. |
| **🧾 Headteacher & Secretary** | Itemized fee collection (`Auto-Allocate`, `Tuition`, `Transport`, `Activity`, `Remedial`), instant receipts, deduplicated parent broadcasts, and **Early Pickup Gate Passes** that sync automatically with the van manifest. |
| **👔 School Director Dashboard** | Executive fee collection analytics and targeted staff communications (All Teachers, All Staff, or custom multi-select staff briefings). |
| **⚙️ Admin & School Setup** | Dynamic school branding, class-level remedial fee toggles (`has_remedials`), staff pre-registration, and student-to-van-stop enrollment. |

</details>

<details>
<summary><b>🎯 Engineering Focus & Core Principles (Click to Expand)</b></summary>
<br/>

- **Offline-First Resilience:** Designing mobile apps with local **SQLite** queues so attendance logs and GPS telemetry never get lost when cellular connectivity drops.
- **Role-Based Security & Clean UX:** Combining Row-Level Security (RLS) in **PostgreSQL/Supabase** with intuitive role-tailored interfaces.
- **Practical Automation:** Replacing manual spreadsheets with automated class rankings, instant PDF generation, and real-time geofenced notifications.

</details>
